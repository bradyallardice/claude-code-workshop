# Session 5

Start here:

1. Make sure you copied the Session 5 slides into your local course workspace.

Replace `[my_workspace]` with wherever you keep your local course files.

Choose exactly one slide-copy option:

Option A: if you already have `[my_workspace]/slides/`, copy just today's PDF:

```bash
cp slides/session5_slides.pdf [my_workspace]/slides/
```

Option B: if you do not have a slides folder yet, copy the whole folder:

```bash
cp -r slides/ [my_workspace]/slides/
```

Do not run both Option A and Option B.

2. Open `../slides/session5_slides.pdf` from your local Session 5 folder. If you are in the course repo root, open `slides/session5_slides.pdf`.
3. For the subagent audit demo, use `option_b/exercise_1/solution_estimate.py`.
4. Open `capstone-template/README.md`.
5. Follow the capstone README to create your team repo on GitHub and copy in the capstone files.
