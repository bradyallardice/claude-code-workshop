# Introduction Structure Audit

Audit the introduction for four moves:

1. Motivate why public attitudes toward AI and offshoring matter.
2. Summarize the Magistro et al. design and main claim accurately.
3. State the group's extension question clearly.
4. Explain what the extension adds to the original paper.

Flag:

- generic motivation
- missing connection to the conjoint design
- unclear extension question
- overclaiming beyond the analysis
- roadmap sentences that do not match the paper

Return a short list of fixes ordered by importance.
