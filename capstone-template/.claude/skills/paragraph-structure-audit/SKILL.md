# Paragraph Structure Audit

For each paragraph, check:

- Does the first sentence state the paragraph's job?
- Is there one main claim?
- Is evidence provided where needed?
- Are transitions clear?
- Does the paragraph contain claims that need citations or output references?

Flag:

- multiple unrelated claims
- unsupported empirical statements
- vague transitions
- AI-sounding filler
- paragraphs that should be split or merged

Return paragraph-level comments with section names.
